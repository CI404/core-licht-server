### 3.2 業務知識（六個致命坑）

見 `docs\交接文件-2026-10-10-第二輪.md`：

1. **UrlList 在 `files/res/`，不在 OBB**
2. **`server='tw_debug_888'`** 決定是否跳 SDK 彈窗
3. **`_fill_required` 會把 `code` 覆寫成 1** → 登入失敗
4. **列舉欄位不能填保守值 1**（`type`/`mode`/`state`/`code`）
5. **`power_speed` 是 int64**，填 `0.0` 會 TypeError
6. **`host` 用 `10.0.2.2`**（QEMU NAT 固定閘道）
