# 安裝指南

從零開始，把《核心：利希特》跑成離線單機。

---

## 0. 先確認你拿到的是「完整包」

```
licht-offline-server\
├── python\python.exe      ← 必須存在（內嵌執行環境）
├── node\node.exe          ← 必須存在（CDN 伺服器用）
├── data\decoded\          ← 必須有 365 個 DataTable_*.json
├── server\mock_game_server.py
└── scripts\1-啟動伺服器.bat
```

**缺任何一個都不是完整包**，請重新取得。

自檢方式：雙擊 `scripts\1-啟動伺服器.bat`，它第一步就會檢查並列出缺少的項目。

---

## 1. 放在哪裡

**路徑含中文與空格是可以的**（本專案已針對這點處理過），例如：

```
D:\核心：GM服务 打包项目\
```

但有兩個建議：
- **不要放在 OneDrive / 雲端同步資料夾**（會被鎖檔）
- **路徑不要過長**（Windows 260 字元限制）

---

## 2. 設定伺服器位址

### 2-1 查出你電腦的 IP

雙擊 `scripts\2-顯示本機IP.bat`

它會列出所有 IPv4，例如：
```
   192.168.1.100
   10.0.0.5
```

### 2-2 決定 `host` 要填什麼

| 遊戲跑在哪裡 | `host` 填 | 原因 |
|---|---|---|
| **MuMu / 雷電模擬器** | `10.0.2.2` | 模擬器用 QEMU NAT，`10.0.2.2` 固定指向宿主機 |
| **真機（同一個 Wi-Fi）** | 電腦的區網 IP，例如 `192.168.1.100` | 手機要透過區網連到電腦 |
| **真機（USB 網路共享）** | 通常是 `192.168.42.129` 之類 | 依實際網段 |

### 2-3 寫進設定檔

**方法 A（推薦）**：在 `2-顯示本機IP.bat` 的提示處直接輸入 IP，它會幫你寫入。

**方法 B（手動）**：用記事本開 `config\server.json`，改這一行：

```json
"host": "192.168.1.100",
```

改完存檔即可，**不用改其他欄位**。

---

## 3. 設定 OBB 資源路徑（CDN 需要）

CDN 伺服器要從「解包後的 OBB 資源」讀檔案。開 `config\server.json`：

```json
"obb_main":  "obb/main/assets",
"obb_patch": "obb/patch/assets",
```

**這兩個路徑必須指向真實存在的目錄。**

### 沒有解包副本怎麼辦

OBB 檔本身就是 zip，直接解開即可：

```powershell
# 1) 找到裝置上的 OBB（或你手上的 OBB 檔）
#    main.138.com.tw99.no23.an.obb
#    patch.138.com.tw99.no23.an.obb

# 2) 解到任意目錄（需要 7-Zip 或改名成 .zip 後解壓）
#    解出來的結構會是 assets\... 
#    把 assets 的完整路徑填進 obb_main / obb_patch
```

用 `1-啟動伺服器.bat` 啟動時，環境檢查會告訴你路徑對不對。

---

## 4. 啟動伺服器

雙擊 **`scripts\1-啟動伺服器.bat`**

正常情況你會看到：

```
  [1/3] 檢查環境設定...
  [OK] 配置表目錄: ...\data\decoded  (365 檔)
  [OK] proto 目錄: ...\data\proto  (64 檔)
  [OK] main OBB assets: ...
  [OK] patch OBB assets: ...
  [OK] CDN 覆蓋目錄: ...\cdn\cdnroot
  [--] 對外主機: 10.0.2.2   登入/遊戲埠: 9001   CDN 埠: 8080
  結果: 全部通過 [OK]
```

然後會彈出兩個新視窗：

| 視窗標題 | 作用 | 不要關 |
|---|---|---|
| `遊戲服 (Python) - 請勿關閉` | TCP 9001 + HTTP 登入服 | ⚠️ |
| `CDN 資源服 (Node) - 請勿關閉` | HTTP 8080 資源下載 | ⚠️ |

### 驗證是否真的起來了

開一個新的命令提示字元：

```cmd
netstat -ano | findstr ":9001 :8080"
```

應該看到兩行 `LISTENING`。

或在瀏覽器打開：`http://127.0.0.1:8080/android_tw/stable/release/config.txt`
應該看到一小段文字（61 bytes 的設定）。

---

## 5. 讓遊戲連到你的伺服器

遊戲客戶端會讀 OBB 裡的 `assets/UrlList_Android.txt` 決定去哪裡抓資源。
原廠寫的是已下線的 `https://pfdh-cdnres.rhinosgamestw.com`，要改成你的電腦。

```cmd
scripts\3-產生UrlList.bat        :: 產生 output\UrlList_Android.txt
scripts\4-部署到設備.bat          :: 用 adb 推到裝置
```

`4-部署到設備.bat` 會：
1. 找 adb（MuMu 內建的、或 PATH 裡的）
2. 列出連接的裝置，請你選一台
3. 把 UrlList 寫進裝置 OBB 的正確偏移位置
4. 問你要不要 `pm clear`（**強烈建議要**，否則讀舊快取）

完成後啟動遊戲即可。

## 6. 常見問題

### Q1：遊戲卡在「評估中」或啟動器畫面

**原因**：CDN 沒起來，或 `UrlList` 沒改成功。
**檢查**：瀏覽器打開 `http://<你的host>:8080/android_tw/stable/release/config.txt`，能不能下載。

### Q2：改完 UrlList 但遊戲行為沒變

**原因**：Unity 快取。遊戲會把讀過的資源快取在 `files/UnityCache/`。
**解法**：
```cmd
adb shell pm clear com.tw99.no23.an
```
**注意**：`pm clear` 會清掉遊戲進度，這是必要的代價。

### Q3：`4-部署到設備.bat` 說寫入失敗

**原因**：真機沒有 root，不能改 `/sdcard/Android/obb/` 下的檔案。
**解法**：見 [`新設備部署.md`](新設備部署.md) 的「無 root 的替代做法」。

### Q4：環境檢查說 OBB 路徑不存在

**原因**：`config\server.json` 的 `obb_main` / `obb_patch` 是別台電腦的路徑。
**解法**：改成你自己解包後的路徑（見上面第 3 節）。

### Q5：埠被佔用

**原因**：可能是上一次的伺服器還在跑，或別的程式用了 9001 / 8080。
**解法**：
```cmd
scripts\6-停止伺服器.bat
```
若仍被佔用，改 `config\server.json` 的 `login_port` / `cdn_port`（記得重新產生 UrlList）。

### Q6：中文顯示亂碼

本專案的 `.bat` 已用 `chcp 65001` + `PYTHONIOENCODING=utf-8` 處理。
若你的系統區域設定特殊導致仍亂碼，**不影響功能**，只是訊息難讀。

---

## 7. 停止伺服器

```cmd
scripts\6-停止伺服器.bat
```

它會依設定檔的埠號找出 PID 並停止，最後驗證埠是否釋放。

也可以直接關掉那兩個「請勿關閉」的視窗。
