## 2. 完整映射鏈（三層貫通）

```
                        children_skin.head_new
                                 │  （6 位數，界面顯示的編號）
                                 ▼
                        DataTable_spine.id
                                 │
                    ┌────────────┴────────────┐
                    ▼                         ▼
      DataTable_spine.path             card_pic_<head_new>.png
      （模型目錄名）                     （卡面小圖，旁支）
                    │
                    ▼
      assets\spine\<path>\
          ├── *.skel    骨骼（Spine 動畫資料）
          ├── *.atlas   圖集描述
          └── *.png     貼圖
```

### 兩套編號系統

`DataTable_children_skin`（333 筆）每筆都有：

```json
{
  "_key": "1430050001",           // = id（10 位，資料庫主鍵）
  "name": "林檎",
  "painter": "薩摩ssssssamo",
  "head_new": "300501",           // ★ 6 位美術編號 == DataTable_spine.id
  "skin_pic": "10101",            // ★ 5 位卡面編號 → card_<skin_pic>.png
  "model": "201001111",           // 戰鬥模型 id（9~10 位，另一套）
  "model_island": 12010011,       // 空島模型 id
  "spine_id": 10000000,           // 舊版 spine id（多數已不用）
  "model_scale": 125,
  "photo_para": [1.5, -344, 0, 0.7],   // 立繪排版 (x, y, ?, scale)
  "photo_para1" ~ "photo_para7",       // 各部位微調
  "skill_show": [[20035101, 1], ...],
  "anim_effect_kd": [["Kd_Sleep", 410003], ...]
}
```

**注意**：`head_new`（6 位）與 `id`（10 位）是**兩套不同的編號**，不要混淆。

## 3. `DataTable_spine`（263 行）— 權威資源表

**路徑**：`raw\decoded\DataTable_spine.rows.json`（174 KB）

| 欄位 | 說明 |
|---|---|
| `id` | ★ 等於 `children_skin.head_new` |
| `path` | ★ 模型目錄名（如 `s_e01003_j1_00`），對應 `assets\spine\<path>\` |
| `path2` | 第二模型（少數角色有） |
| `click` | ★ **點擊互動動作清單**，如 `[["normal",0],["angry",0],["happy",0],...]` |
| `click2` | 第二組點擊動作 |
| `para` / `para1`~`para4` | 立繪排版參數 `[x, y, ?, scale]` |
| `scenario_para` | 劇情演出時的排版 |
| `dialog_para` | 對話框排版 |
| `enter_voice_id` | 登場語音 id |
| `timeline_id` | 時間軸 id（演出用） |
| `is_show_main_bg` | 是否可作主界面背景 |
| `need_connect_anim` | 是否需要拼接動畫（`bg1`/`bg2`/`body` 分部件的原因） |
| `spine_effect` | 特效設定 |
| `particles_timepoint` | 粒子時間點 |
| `sound_delay` / `ui_delay_occurrence` | 音效/UI 延遲 |
| `default_index` / `default_mix` | 預設動作索引/混合 |

### 實測統計

| 項目 | 數量 | 比例 |
|---|---|---|
| 總行數 | **263** | — |
| `path` 在磁碟上找得到 | **257** | **97.7%** |
| 含 `.skel` 骨骼檔 | **257** | 97.7% |
| 能對到角色名（`head_new`） | **204** | **77.6%** |
| 有 `click` 互動動作 | **109** | 41.4% |

> **對不上的 56 行**：多為 NPC、未實裝角色、或特殊演出物件（`n00003`、`n00008`、`war_order_*` 等）。
> **對不上的 1 個 path**：`s_l41003_j1_00`（OBB 內就沒有這個 bundle）。

### 4.3 `.config.json` 說明

`assets\spine\<dir>\_<hash>.config.json` 內容多為：

```json
{ "_raw_bytes": 76 }
```

**這只是提取器的元資料，不是真正的 Spine 設定。**
真正的設定在 `E:\核心：利希特\核心live2d\<模型名>\<name>.config.json`（23 套），格式為：

```json
{
  "type": 9,
  "hit_areas": [{"name":"bone472","id":"bone472","width":2.0,"height":2.0}],
  "motions": {"idle":[{"file":"idle"}], "tap":[{"file":"idle1"}]},
  "skeleton": "TextAsset/spine_a04004_01.skel",
  "atlases": [{"atlas":"…", "tex_names":[…], "textures":[…]}],
  "controllers": {"intimacy_system":{}, "slot_opacity":{}, "slot_color":{}}
}
```

**`hit_areas` = 可點擊區域**（配合 `DataTable_spine.click` 的動作清單使用）。

## 6. 若要做「資料查詢 / 圖鑑」類附屬產物

> ⚠️ 再次提醒：**不要**重寫遊戲界面。以下僅適用於「遊戲外」的資料瀏覽工具。

1. 讀 `docs\角色資源清單.json`（263 筆，含 name / path / click / para）
2. 立繪顯示：`assets\spine\<path>\*.png`（注意 `_body` / `_bg1` / `_bg2` 是**分層**的，需疊合）
3. 動作播放：`pixi-spine` 或 `spine-webgl` 載入 `.skel` + `.atlas` + `.png`
4. 互動：`DataTable_spine.click` 列出可用動作名 → 對應 `.skel` 內的 animation
