## 協定規格（供日後維護參考）

```
C2S: [u16 BE len = 總長-2][u16 BE uniq][u8 sId][u8 mId][body XOR passArr[(uniq+i)&0xFF]]
S2C: [u16 BE len = 總長-2][u8 sId][u8 mId][u8 zflag][body XOR passArr[((sId*16+mId)+i)&0xFF]]
連線建立時客戶端先送裸 2 bytes 01 02 → 必須丟棄，不可回送
zflag != 0 ⇒ body 是 zlib
```

**兩條必須遵守的伺服器規則**：
1. **`45_6` 只回一次** —— 客戶端 handler 收到回應會再送一次，每次回會變成無限 ping-pong（實測 2773 次/秒 → 全黑）
2. **`_fill_required` 的陷阱** —— 對 `type` / `mode` / `state` 這類**帶語意的列舉**欄位不能亂填保守值 `1`（修復 #2 就是踩到這個）
