================================================================================
  核心：利希特 — 離線伺服器
  安裝說明（第一次使用請從這裡開始）
================================================================================

這個資料夾已經「自帶執行環境」，你不需要安裝 Python 或 Node.js。


--------------------------------------------------------------------------------
  三步驟開始
--------------------------------------------------------------------------------

【步驟 1】設定要用哪個 IP
    雙擊   scripts\2-顯示本機IP.bat
    它會列出你電腦的 IP，並可以幫你寫進設定檔。

      * 用 MuMu / 雷電模擬器     →  host 保持 10.0.2.2（不用改）
      * 用真機（同一個 Wi-Fi）   →  host 填電腦的區網 IP，例如 192.168.1.100

【步驟 2】啟動伺服器
    雙擊   scripts\1-啟動伺服器.bat
    會開啟兩個視窗，標題寫著「請勿關閉」→ 那是伺服器本體，不要關。

    第一次啟動時 Windows 可能問「是否允許通過防火牆」
    → 兩個都要勾「私人網路」並允許

【步驟 3】讓遊戲連過來
    雙擊   scripts\3-產生UrlList.bat      （產生要寫進遊戲的設定）
    雙擊   scripts\4-部署到設備.bat        （用 adb 寫進裝置，並清除快取）

    完成後啟動遊戲即可。


--------------------------------------------------------------------------------
  設定檔只有一個
--------------------------------------------------------------------------------

    config\server.json

    最常需要改的是這兩項：

      "host"        →  伺服器位址（步驟 1 就是在改這個）
      "obb_main"    →  原廠 main OBB 解包後的 assets 目錄
      "obb_patch"   →  原廠 patch OBB 解包後的 assets 目錄

    CDN 伺服器要從 obb_main / obb_patch 讀遊戲資源，
    所以那兩個路徑必須指向真實存在的目錄，否則遊戲下載資源會失敗。


--------------------------------------------------------------------------------
  檔案與資料夾
--------------------------------------------------------------------------------

    1-安裝說明.txt        本檔
    README.md             專案總覽（含架構圖）

    config\server.json    ★ 唯一需要手動改的檔案
    config.py             設定載入模組

    scripts\              一鍵操作腳本（見上方步驟）
        1-啟動伺服器.bat
        2-顯示本機IP.bat
        3-產生UrlList.bat
        4-部署到設備.bat
        6-停止伺服器.bat

    server\               伺服器程式
        mock_game_server.py   遊戲服 TCP + HTTP 登入服（同一埠 9001）
        player_data.py        玩家資料（全部從配置表推導）
        lichter_wire.py       TCP 協定編解碼

    cdn\                  CDN 資源伺服器
        server2.js            監聽 8080
        cdnroot\              伺服器清單 / 公告（可自行編輯）

    data\                 執行期資料
        decoded\              365 個遊戲配置表
        proto\                64 個協定描述

    python\               內嵌 Python 3.12.14（含 protobuf 7.36.2）
    node\                 內嵌 Node.js v24.21.0

    output\                UrlList 產出位置
    runtime\               日誌檔（出問題時看這裡）

    docs\                 詳細文件
        安裝指南.md
        新設備部署.md
        已完成修復清單.md     ← 這個專案修過哪些 bug、證據在哪


--------------------------------------------------------------------------------
  出問題時
--------------------------------------------------------------------------------

  Q：遊戲卡在「評估中」
  A：CDN 沒起來。用瀏覽器開 http://127.0.0.1:8080/android_tw/stable/release/config.txt
     能下載到內容才算正常。

  Q：改了 UrlList 但遊戲沒反應
  A：Unity 快取。必須執行 adb shell pm clear com.tw99.no23.an

  Q：部署時說寫入失敗
  A：見 docs\新設備部署.md 第四節（用 patch_obb.py 在電腦上改）

  Q：想看伺服器收到什麼
  A：runtime\mock-server.log（遊戲服）、runtime\cdn-requests.log（CDN）

  Q：埠被佔用
  A：scripts\6-停止伺服器.bat，或改 config\server.json 的埠號

  Q：恢復原廠（不想玩了）
  A：把 patch OBB 換回原廠版本即可（本工具會自動備份成 .bak）


--------------------------------------------------------------------------------
  重要提醒
--------------------------------------------------------------------------------

  * 本專案只做「伺服器模擬」，遊戲本體與資源完全保持原廠，不改遊戲程式。
  * 唯一動到遊戲檔案的地方是 patch OBB 內的 UrlList_Android.txt
    （把 CDN 位址從已下線的原廠網址改成你自己的電腦）。
  * 遊戲版權屬原權利人，請勿散布遊戲資源或作商業用途。
