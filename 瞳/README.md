## 為什麼瞳值得單獨做一個專項

瞳（Hitomi）是《核芯：利希特》**最特殊的角色**：

| 特殊性 | 實測數據 |
|---|---|
| **唯一有多個號碼段的角色** | `100000~100007` + `9100001~9100007`（其他角色只有 4 位數編號） |
| **形態最多** | **15 個**（其他角色通常 1 個） |
| **皮膚最多** | **32 個**（第二名「舊影」只有 7 個，是 4.5 倍） |
| **模型目錄最多** | **20 個** Unity Prefab 目錄（E01001 系列 ×16 + E01003 系列 ×2 + common ×2） |
| **資源最完整** | 1,373 檔 / **54.63 MB**（20 Prefab + 37 Spine + 2 Live2D） |
| **有完整的角色設定** | 5 篇適格體檔案 + 官方介紹 + 4 條世界觀詞條 |
| **有專屬的關係人物** | 製造者「亞述桐」（已故），檔案刻意關聯 |
